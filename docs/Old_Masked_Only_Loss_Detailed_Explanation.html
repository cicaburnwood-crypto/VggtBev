老版本 Masked-only BEV Loss
详细技术说明

4. 数学定义

对一个分支 b（single 或 merged），令像素集合为 Ω，masked target 为 Yi。定义：

mi = 𝟙[Yi ≠ unknown]，  yi = 𝟙[Yi = occupied]，  pi = σ(oi)，  qi = σ(ai)

mi 是 observation/known mask；yi 是 occupied 二值标签。只有 mi=1 的像素拥有 occupancy 真值。

4.1 Masked occupancy BCE

Locc = − 1/|M| · Σi∈M [ yi log pi + (1−yi) log(1−pi) ]

其中 M={i | mi=1}。unknown 像素不进入求和，所以无论模型在 unknown 区域把 occupancy logit 改成什么值，都不会改变 Locc。如果整个 target 没有 known 像素，代码返回一个与图相连但数值为 0 的 loss。

4.2 Observation-mask BCE

Lobs = − 1/|Ω| · Σi∈Ω [ mi log qi + (1−mi) log(1−qi) ]

这个损失覆盖全图，负责学习“哪些位置应当输出 known”。因此模型可以在 runtime 将 occupancy 结果裁到其预测的 observed 区域。它不是 occupancy confidence，也不表示预测是否正确。

4.3 Occupied Dice

Ldice = 1 − [2Σi∈Mpiyi + 1] / [Σi∈Mpi + Σi∈Myi + 1]

Dice 只在 known/masked 区域中计算，用来缓解 occupied 像素稀少导致的类别不平衡。分子和分母中的 +1 是平滑项，避免空目标或小区域产生除零与极端梯度。

4.4 单分支总损失

Lb = woccLocc + wobsLobs + wdiceLdice

历史配置使用：

wocc=1.0， wobs=0.5， wdice=0.25

5. Single 与 merged 的聚合

同一个 loss 分别作用于 single 与 merged 输出，最后线性组合：

LBEV = wsLsingle + wmLmerged

历史默认权重为 ws=0.5、wm=0.5，因此：

LBEV = 0.5Lsingle + 0.5Lmerged

merged decoder 直接读取多帧 token；该 loss 并未定义“先预测多个 single 再合并”的二级模型。

6. 梯度到底作用在哪里

区域/参数occupancy BCEoccupied Diceobservation BCE
observed free有梯度，推动 p→0进入分母，抑制 false occupied推动 q→1
observed occupied有梯度，推动 p→1进入交集与分母推动 q→1
unknown无梯度无梯度推动 q→0
complete-only/occluded truth根本不作为 target 进入 loss

因此，该版本不会鼓励模型猜测障碍物后方或视野外的 free/occupied。unknown 区域里的 occupancy logit 可以是任意值，但部署时必须被 predicted observed mask 屏蔽。

7. 与“置信度”的关系

该老版本没有单独的 confidence head，也没有 Beta/Dirichlet evidence。两个 sigmoid 输出分别表达：

  • p：在已知区域里是 occupied 的概率；
  • q：该像素是否属于 observed/known 区域的概率。

q 高并不代表 occupancy 判断正确；它只代表模型认为该像素应该被显示。因此不能把 q 直接当作导航置信度，也不能从它区分“模型确定地预测 free”和“模型只是认为这里被观察到”。

8. 代码级伪代码

def masked_branch_loss(occupancy_logit, observed_logit, target):
    known = target != UNKNOWN_112
    occupied = target == OCCUPIED_0

    if known.any():
        occupancy_bce = BCEWithLogits(
            occupancy_logit[known], occupied[known]
        )
        occupied_dice = dice(sigmoid(occupancy_logit[known]),
                             occupied[known])
    else:
        occupancy_bce = 0
        occupied_dice = 0

    observation_bce = BCEWithLogits(observed_logit, known)

    return 1.0 * occupancy_bce \
         + 0.5 * observation_bce \
         + 0.25 * occupied_dice

loss = 0.5 * masked_branch_loss(single_prediction, single_masked_gt) \
     + 0.5 * masked_branch_loss(merged_prediction, merged_masked_gt)

9. 该设计的优点

  1. 监督边界清晰：只有传感器直接观察到的 free/occupied 影响 occupancy，不会把未知区域的先验猜测注入 observed 学习。
  2. 实现简单：两个 BCE 加一个 Dice，梯度路径容易检查，几乎没有 completion 与 observed 之间的冲突。
  3. 适合几何转换验证：当目标只是验证 RGB→observed BEV 的可行性时，它比完整补全目标更容易定位错误。
  4. single/merged 对称：相同数学形式便于比较单帧转换与多帧聚合。

10. 已知问题与失败模式

  1. 无法补全：unknown 区域没有 occupancy 梯度，因此模型不应被期待输出障碍物后方的完整状态。
  2. 没有真正的置信度：observed probability 只是 mask 概率，不是预测正确率或 epistemic uncertainty。
  3. occupied Dice 可能面积化稀疏表面：observed occupied 往往只是一条 first-hit surface。Dice 倾向于提高区域重叠，可能推动模型把细表面变厚。
  4. 全图 mask BCE 有类别不平衡：unknown 面积通常很大；未使用 class weight/focal loss 时，mask 学习可能被背景数量主导。
  5. unknown 内 occupancy 无约束：如果 runtime 忘记使用 observed mask，unknown 区域可能暴露随机或数据先验式 occupancy。
  6. single/merged 固定 0.5/0.5：两个任务难度与像素数不同，固定等权并不保证梯度规模相等，可能出现一支表现好、另一支较差。

11. 历史验证指标

对应 metrics 以阈值 0.5 将 sigmoid 输出二值化，并报告：

  • known 区域内 occupied IoU/F1 与 free IoU/F1；
  • 全图 unknown IoU/F1；
  • occupied/free/unknown 三类 macro F1；
  • occupancy ECE 与 observation ECE；
  • occupied boundary Chamfer distance。

这些指标中，observation ECE 仍然只是 known-mask 概率校准，不等于 occupancy correctness confidence。

12. 与当前 P1B 的兼容性

该 loss 不能原样粘贴到当前 P1B，原因是当前输出为：

  • alpha_occupied / beta_free Beta evidence；
  • fov_support_logit；
  • 并行 metric scale token。

如果要在不改变当前 P1B 模型结构的情况下复现 masked-only 行为，数学上的等价迁移应当是：

  1. 只保留 observed free 与 observed surface 的 evidential NLL；
  2. 保留 FOV/support loss，但明确它只学习几何支持范围；
  3. 令 guessed NLL、guessed Dice、guessed evidence calibration、relation loss 全部为 0；
  4. 令 guessed_region_weight=0，避免 direct loss 被旧分母缩小；
  5. 关闭 completion PCGrad；
  6. scale loss 可作为独立任务保留，它不属于 BEV completion。
不建议恢复的部分：不要把 observed_logit 当作置信度重新加入当前模型；当前 Beta evidence 已提供更清晰的 confidence/uncertainty 语义。

13. 最终总结

老版本 masked-only loss 的本质是“先学习 observed mask，再只在 mask 内学习 free/occupied”。它完全避免 completion 对 observed 的梯度干扰，适合作为 RGB→直接观测 BEV 的基线；代价是无法预测遮挡区域，也没有可解释的 occupancy confidence。当前 P1B 若需要同类基线，应复用其“监督区域隔离”思想，而不是恢复旧的双 sigmoid 输出结构。
